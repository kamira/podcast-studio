## 動機

使用者指示(2026-10-26,原話):「另開一筆小 CHG 處理兩個缺口(生圖與聲線設定接上程式、workflows/ 使用者檔列入忽略),草稿給我過確認閘;同時進行 CHG-01 驗收。」

兩個缺口都是 CHG-20261022-01 T13 更新結構文件時記下的〔觀察〕:

1. 設定頁可以編輯 `roles.image`(`model`、`steps`)與 `roles.voice`(`wav`、`text`),通過 `settings.validate` 後存進 `config/studio.db`;但 `media.generate_image()` 仍用 `taiwan_ai.FLUX` 與固定 `--steps 4`,`taiwan_ai.speak()` 仍用 `VOICE_WAV` / `VOICE_TEXT` 常數——**使用者存了設定卻不生效**。
2. 從畫布存檔會建立未追蹤的 `workflows/<名稱>.json`;`scripts/deploy_local.sh` 遇到不乾淨的工作樹(含未追蹤檔)會中止部署,所以**存一次工作流程就無法部署**。

使用者指示(2026-10-26,原話):「影片合成兩個缺陷(float WAV 讀不到長度、影片比聲音長)併入 CHG-20261026-01,加 task 後草稿一起給我過確認閘;修好後重跑 CHG-01 驗收的端到端步驟。」

兩個缺陷都是 ACC-20261026-01(CHG-20261022-01 驗收)以真模型實測發現:

3. `media.wav_seconds()` 以標準庫 `wave` 讀長度;BreezyVoice 輸出的是 IEEE float WAV(format 3,22050 Hz,單聲道,float32),`wave` 丟 `wave.Error: unknown format: 3`。只要帶字幕(預設範本、MCP `make_video(script=…)`),合成影片**一定失敗**,沒有 MP4 與 SRT(ACC A1、A3、A8)。
4. 不帶字幕時影片軌 49.5 秒、音軌 17.04 秒:`-loop 1` + `-shortest` 沒有在聲音結束時截止,片尾多出約 32 秒靜止畫面(ACC A3、A8)。

| WAV 長度讀法(T4) | 自寫 RIFF/WAVE 解析(`struct`)vs 以 imageio-ffmpeg 取長度 | 只能二選一、取最小;已查證 imageio-ffmpeg 0.6.0 只附 `ffmpeg` 執行檔、**沒有 `ffprobe`**(`imageio_ffmpeg/binaries/` 只有 `ffmpeg-macos-aarch64-v7.1`),改用它就得另開 `ffmpeg -i` 子程序並解析 stderr 的 `Duration:` 文字(精度 10 毫秒、格式隨版本變) | **代決**:自寫解析。只用標準庫 `struct`、不開子程序、不加依賴、精度為取樣等級;支援 PCM(1)、IEEE float(3)、WAVE_FORMAT_EXTENSIBLE(0xFFFE,以 SubFormat GUID 前 2 位元組判斷是 1 或 3);長度 = data 位元組數 ÷(聲道數 × 每樣本位元組數)÷ 取樣率。代價:非 WAV(MP3 / M4A)仍讀不到長度(ADP-7,本筆不處理) |

| 壞檔的錯誤 | 沿用 `wave.Error` vs 自訂繁中錯誤 | 節點與 MCP 會把錯誤訊息顯示給使用者 | **代決**:`wav_seconds()` 對不是 RIFF/WAVE、缺 `fmt ` 或 `data` chunk、不支援的編碼、欄位為 0 等情況一律丟 `ValueError`,訊息為繁中並指出原因(例:「音檔不是 WAV 格式」「WAV 編碼不支援(format 85)」);不洩漏本機絕對路徑以外的內容(訊息不含路徑) |

**代決事項**(Guideline 與使用者指示推導不出,由 agent 先決定,確認閘請覆核):

1. 讀設定時機與介面:每次呼叫經新增的 `taiwan_ai.role_config()` 重讀。
2. `generate-image` 節點不新增 `steps` 參數,步數只走設定。
3. `--base-model schnell` 維持固定。
4. mflux 子程序加 `HF_HUB_OFFLINE=1`(沿用其餘環境變數)。
5. 移除 `taiwan_ai.FLUX`、`VOICE_WAV`、`VOICE_TEXT`;MCP `list_models` 的 `image` 列改回報設定值。
6. 不新增 `settings.validate` 規則。
7. 從畫布覆寫 `default` 只記錄、不改程式(替代:伺服器拒絕覆寫 `default`)。
8. 不改 `scripts/deploy_local.sh`。
9. 風險分級判「高」(理由見標頭)。
10. (T4)WAV 長度以自寫 RIFF/WAVE 解析取得,不用 imageio-ffmpeg(它沒有 `ffprobe`,改用要另開子程序解析文字)。
11. (T5)WAV 音檔加 `-t <秒數>` 並保留 `-shortest`;輸出影格率由 `-r 2` 改為 `-r 10`(依實測,`-r 2` 的 0.5 秒影格間隔達不到 ≤ 0.1 秒)。
12. (T5)非 WAV 音檔沿用現況(不加 `-t`),ADP-7 不在本筆處理。
13. (T4)壞檔與不支援的編碼丟繁中 `ValueError`,訊息不含路徑。
14. (T5 測試)用 17.3 秒的 float WAV,不用 3 秒——3 秒重現不出缺陷,測不到修正。

## 安全影響

|------|----------|-----------------|
