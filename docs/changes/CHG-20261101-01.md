## 動機

2026-11-01 使用者問:「claude的語音模型輸出非常自然的原因是什麼？」。派發者回答時先說明 Anthropic 沒有公開實作,再列出一般原因,並對照 podcast-studio 目前使用的 BreezyVoice,提出三個不換模型就能著手的方向:

1. 把腳本改寫成口語(短句、去書面語,數字與縮寫轉成念法)。
2. 拉長合成的切段單位,或在段與段之間保留上下文,避免逐句合成使語調每句歸零、句與句接不起來。
3. 換一個更像在聊天的 zero-shot 參考音檔(參考音檔的說話風格會直接影響語調)。

使用者接著依序回覆,原話:

- 「可以納入低優先度待處理事項」
- 「可以放在之前提到的對話機制調整文案上」——指 Guideline §4.6 可選功能「AI 寫稿可用對話方式調整草稿內容」
- 「開 CHG 寫進 §4.6」
